## 思路梳理

写一写文档吧，想做的socket、文件管理，做不到的webdav、nextcloud、zerotier one、邮箱、声纹对比

### 功能

1. 登录登出
   - 非对称加密登录
2. 文件管理
   - 上传
   - 下载
   - 记录文件
   - 分析文件
   - 获取重复文件
   - 删除文件
   - 批量删除文件
   - 按路径获取文件（夹）
   - 按文件名获取文件信息
   - 按索引查询文件
3. 文档管理
   - pdf 分页
4. 压缩包管理
   - 获取第一层文件名，存储到索引列
5. 音乐管理
   - 音频文件表
   - 音乐文件表
   - 歌单表（音乐ID、歌曲名称）
   - 文件移动后尝试寻找文件
   - 找不到文件尝试下载文件
   - 批量移动队列
   - 按名称列表生成歌单
6. 视频管理
   - 获取截图
   - 批量获取截图
7. socket.io
   1. 用户
      - 用户与socketId 绑定（数据库适配器？）
   2. 房间
      - 创建房间（用户-房间）
      - 查询我的房间及聊天好友
      - 退出房间
      - 进入房间
      - 删除房间及消息
   3. 消息
      1. 聊天
      2. 分页查询消息
      3. 系统消息
   4. 好友系统[user__user](#user__user)
