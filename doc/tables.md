# 数据库表

## 数据库表 列表

| 表名            | 标题        | 说明                         |
| :-------------- | :---------- | :--------------------------- |
| Base            | 基础表      | 只是父类，**不是表**             |
| Dictionary      | 字典        |                              |
| Directory       | 目录        |                              |
| File            | 文件        | 拥有树形结构                 |
| FileGroup       | 文件组      | 歌单等                       |
| FileToFileGroup | 文件_文件组 | 文件与文件组关联表           |
| Goods           | 物品        | 衣物、玩家等物品             |
| index           | 导出entity  | **不是表**                       |
| Person          | 人          |                              |
| QueueJob        | 队列工作    |                              |
| Schedule        | 定时器      |                              |
| Space           | 空间        | 房间、衣柜、抽屉、箱子等空间 |
| TagTree         | 标签树      | 标签，拥有树形结构           |
| Task            | 任务        |                              |
| TaskNode        | 任务节点    |                              |
| Todo            | 代办        |                              |
| Tree            | 树          | 文件、标签等树形结构表的父类 |
| User            | 用户        |                              |

## 部分表的关系

有些看起来很像的表，这里解释他们的关系与区别

### QueueJob、Schedule

### Task、Todo

两者都是计划的一种
task 长期的，工程性质的，如软件开发，需要整理需求、开发、测试、发布等步骤；“异步的”
todo 临时的，可快速完成，一步完成，一次性或需要重复的；“同步的”

### Person、User

person 真实的人员信息，如姓名、性别、年龄、住址、身份证号、多种联系方式 等
user 人员的用户信息，只包含昵称、密码等工作用信息
